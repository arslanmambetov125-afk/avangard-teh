# KINGSTORE Motion Concept

Standalone motion-first Next.js concept for KINGSTORE Ufa.

## Stack
- Next.js App Router
- React + TypeScript
- GSAP + ScrollTrigger
- CSS transforms / CSS component layers / particle field

## Notes
- Publicly available brand/product imagery is used for a non-official redesign concept.
- Trade-in and installment figures are clearly marked as demo/preliminary.
- The preview is `noindex` by design.
